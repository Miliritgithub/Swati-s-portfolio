# Project

Base scaffold for website cloning via the `clone-website` skill.

Stack: Next.js 16 (App Router, `src/`, TypeScript, Turbopack), Tailwind v4, shadcn/ui (radix base, nova preset, CSS variables).

Design direction: `clone-website` — pure emulation of the target site. Do not apply an independent design skill; the target URL is the design source of truth.

Clone artifacts live in `docs/research/<hostname>/`, component specs in `docs/research/components/`, extracted assets and screenshots in `docs/design-references/<hostname>/`.
